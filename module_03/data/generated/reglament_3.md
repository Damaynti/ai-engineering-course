# Внутренний регламент предприятия «ПромТех»:  
**«Регламент реагирования на инциденты на технологических установках»**

## Шапка документа

```
# Название документа: Регламент реагирования на технологические инциденты
# Номер документа: РГЛ-РИ-007
# Версия: 3.1
# Утверждён генеральным директором ООО «ПромТех» И.И. Ивановым
# Дата утверждения: 10.09.2023 г.
# Дата вступления в силу: 15.10.2023 г.
# Область действия: Производственные цеха №1–№3, участки №10–№15
# Периодичность пересмотра: один раз в три года
```

## 1. Общие положения

### 1.1 Цель документа
Определить порядок действий персонала производственных подразделений при возникновении инцидентов на технологических установках.

### 1.2 Термины и определения
Инцидент — нарушение нормального режима работы технологического оборудования, приводящее к отклонению от установленных норм.

---

## 2. Порядок действий при инциденте

### 2.1 Первичные мероприятия
При обнаружении инцидента ответственное лицо немедленно:
- Остановить установку (пункт 2.1.1);
- Сообщить руководителю смены (пункт 2.1.2);
- Оформить заявку на останов установки по форме РГЛ-Ф-08 (пункт 2.1.3).

#### Проверяемые факты:
- Пороговое значение отклонения температуры — +120 °C (пункт 2.1.1);
- Ответственное лицо — оператор установки (пункт 2.1.2);
- Форма заявки — РГЛ-Ф-08 (пункт 2.1.3).

### 2.2 Оценка ситуации
После получения сигнала ответственный инженер оценивает ситуацию и принимает решение о дальнейших действиях:
- В случае угрозы безопасности жизни людей — остановить установку незамедлительно (пункт 2.2.1);
- В остальных случаях принять меры по локализации инцидента (пункт 2.2.2).

#### Проверяемые факты:
- Срок оценки ситуации — до 15 минут после поступления сигнала (пункт 2.2.1);
- Решение об остановке принимает руководитель смены совместно с инженером (пункт 2.2.1);
- Инженер по охране труда составляет акт о происшествии по форме РГЛ-Ф-09 (пункт 2.2.2).

---

## 3. Действия после инцидента

### 3.1 Локализация последствий
После принятия решения ответственное лицо организует мероприятия по ликвидации последствий инцидента:
- Изоляция поврежденного оборудования (пункт 3.1.1);
- Отключение аварийных участков (пункт 3.1.2).

#### Проверяемые факты:
- Время изоляции оборудования — не позднее 30 минут после обнаружения инцидента (пункт 3.1.1);
- Пороговое давление отключения аварийного участка — 1,6 МПа (пункт 3.1.2).

### 3.2 Документация
По завершении мероприятий составляется отчет по форме РГЛ-Ф-10, содержащий:
- Причины инцидента;
- Мероприятия по устранению последствий;
- Предложения по предотвращению повторения инцидента.

#### Проверяемые факты:
- Форма отчета — РГЛ-Ф-10 (пункт 3.2);
- Срок составления отчета — не позднее трех рабочих дней после инцидента (пункт 3.2).

---

## 4. Ответственность и полномочия

### 4.1 Персонал, участвующий в реагировании
Ответственными лицами являются:
- Руководитель смены (пункт 4.1.1);
- Инженер по охране труда (пункт 4.1.2);
- Начальник участка по эксплуатации (пункт 4.1.3).

#### Проверяемые факты:
- Полномочия руководителя смены — принятие решений о приостановлении работы установки (пункт 4.1.1);
- Обязанности инженера по охране труда — составление акта происшествия (пункт 4.1.2);
- Ответственность начальника участка — организация работ по восстановлению нормальной работы установки (пункт 4.1.3).

---

## 5. Исключения и особые случаи

### 5.1 Работы вне графика
Работы на оборудовании, выходящем за рамки данного регламента, регулируются отдельным регламентом РГЛ-ХХ-01.

### 5.2 Отсутствие данных о типе оборудования
При отсутствии полной информации о типе оборудования решение принимается инженером по эксплуатации индивидуально.
