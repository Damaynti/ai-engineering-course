# ai-engineering-course

## Troubleshooting

### 'Ошибка 400: Can't decode 'Authorization' header'
**Что видел:** ошибка при запуске после того, как вписала последовательность случайных символов.
**Почему:** ключ указан в неправильном формате, из-за чего сервер не может его распознать.
**Что сделал:** вернула настоящий ключ.

### 'Ошибка ModuleNotFoundError: No module named 'dotenv''
**Что видел:** ошибка при запуске программы после того, как вышла из виртуального окружения .venv.
**Почему:** виртуальное окружение .venv не было активировано, поэтому Python не нашёл необходимую библиотеку dotenv.
**Что сделал:** активировала виртуальное окружение .venv и повторно запустила программу.

### 'Ошибка 401: credentials doesn't match db data'
**Что видел:** ошибка при запуске после того, как поменяла один символ в ключе.
**Почему:** указан ключ, который не проходил авторизацию. 
**Что сделал:** вернула настоящий ключ.
